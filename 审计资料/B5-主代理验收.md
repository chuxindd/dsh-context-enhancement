## 结论

B5 验收通过：Stable Task State 已使用 lifecycle 固定 surface slot，具备独立 token 预算 I、staleness 标记、compaction 预算对账与真实压缩遮蔽后的安全重建。

## B5.1 固定槽位

- 首次 stable 通过 surface append 创建 slot；
- 后续 revision 通过 `surfaceOp.replace` 替换旧 slot；
- replacement 带 sourceEventSeqs、old/new revision、digest、cursor 与 generation；
- dispose/resume/fork 按 Session object + lifecycle + 日志重新解析；
- source-index 分类为 `task-state-slot`，不当作普通 original；
- runtime-context 模板保留但值为空，避免 DSH append-only snapshot 累积。

主代理验证：fixed-slot/prompt/render 34/34，typecheck 通过。

## B5.2a 注入预算与 staleness

- `maxBytes` 与 token 预算 `maxTokens` 独立；默认 I=512 tokens；
- 优先使用真实 token meter，缺少时用保守 fallback，不使用 chars/4；
- Goal/TODO 权威最小表示优先；最小表示仍超预算时 typed blocked，不注入误导性半截；
- stable cursor 落后 eligible high-water 时显示 stale marker，catch-up 后恢复 fresh；
- source/diagnostics 记录 injectionTokens、budgetTokens、staleness、high-water、truncation；
- compaction G 只扣一次实际 slot token，并在 ledger 中记录 usage baseline。

主代理验证：预算/slot/compaction 相关 101/101，typecheck 通过。
